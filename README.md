# Discover Ho Chi Minh City 🇻🇳

An interactive website that helps users create a personalized Ho Chi Minh City itinerary based on their preferred vibe, budget, and available time.

## Features

- 🌃 Choose your Saigon vibe
- 💰 Select your budget
- ⏱ Choose your available time
- 🗺 Generate a personalized itinerary
- 🎲 Surprise Me option
- 📧 Send the itinerary to your email
- 📊 Personalized experience scores
- 📱 Responsive web design

## Technologies

- HTML
- CSS
- JavaScript
- EmailJS
